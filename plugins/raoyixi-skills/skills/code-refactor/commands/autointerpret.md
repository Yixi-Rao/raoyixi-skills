# /autointerpret

解读指定文件中的特定函数。

## 参数

- `file_path` (必需): 包含函数的文件的绝对路径
- `function_name` (必需): 要解读的函数名

## 描述

此命令会分析文件中的特定函数，提供详细的功能解读。

## 用法示例

```
/autointerpret /lpai/code/api.py process_request
/autointerpret /lpai/code/data-processing/parse_sql_data.py extract_data
```

## 命令功能

当你使用 file_path 和 function_name 调用此命令时，会执行以下操作：

1. 读取指定路径的文件
2. 定位指定名称的函数
3. 分析并提供详细解读，包括：
   - 函数的目的和作用
   - 参数说明及其类型
   - 返回值说明
   - 核心逻辑和操作流程
   - 潜在的边界情况
   - 依赖关系和导入
   - 使用示例（如适用）

## 执行步骤

1. 首先使用 Read 工具读取 `file_path` 指定的文件
2. 在文件中搜索名为 `function_name` 的函数定义
3. 分析函数代码，提供清晰的中文解读：
   - 函数摘要：简洁说明函数的核心功能
   - 参数详解：每个参数的含义、类型和用途
   - 返回值：返回值的类型和含义
   - 逻辑流程：逐步解释函数的执行逻辑
   - 异常处理：函数如何处理错误和边界情况
   - 调用示例：提供实际使用示例
   - 相关依赖：列出函数依赖的其他模块或函数

请用清晰、易懂的中文进行解读，帮助用户快速理解函数的实现细节。
